npm install -D vite-svg-loader

### 3. 两种方案的对比总结

| 特性           | 方案一: `vite-plugin-svg-icons` (SVG Sprite)        | 方案二: `vite-svg-loader` (SVG 组件化)                   |
| :------------- | :-------------------------------------------------- | :------------------------------------------------------- |
| **打包产物**   | 单个 SVG Symbol 集合（Sprite），通过 `<use>` 引用。 | 多个独立的 Vue 组件（每个 SVG 文件一个）。               |
| **性能**       | **最佳**。只加载一次 Sprite，浏览器高效缓存。       | 较好。利用 **`defineAsyncComponent`** 实现懒加载。       |
| **颜色控制**   | 通过 `<use :fill="color">` 属性完美控制。           | 通过 `<component :fill="color">` 属性传递给 SVG 根元素。 |
| **样式隔离**   | 极佳。所有图标在 Shadow DOM 中，不会相互影响。      | 较好。作为独立组件，但也可能受到全局 CSS 影响。          |
| **配置复杂度** | 略复杂（需配置 `iconDirs` 和 `symbolId`）。         | **非常简单**（只需启用插件）。                           |

**建议：**

- 如果您的项目图标 **数量非常多** (几十个甚至上百个)，且对 **初始加载性能** 要求极高，请使用 **方案一 (SVG Sprite)**。
- 如果您的项目图标 **数量适中**，追求 **最简单的配置** 和 **最直观的组件使用** 方式，请使用 **方案二 (SVG 组件化)**。
